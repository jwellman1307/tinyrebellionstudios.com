# tinyrebellionstudios.com

Official website for Tiny Rebellion Studios.

Tiny Rebellion Studios creates practical mobile apps and independent games built around real problems, meaningful choices, work, money, pressure, and user control.

## Current projects

- **Between Checks** — A privacy-focused Android budgeting app that helps people understand what they can safely spend before their next paycheck.
- **Definitely Productive** — A satirical office-life game about surviving the workweek and climbing a questionable corporate ladder.
- **State of Dissent** — A long-term narrative survival game focused on work, family, resistance, and consequence.
- **OffSync** — An early scheduling app concept for finding shared days off across different work schedules.

## Website

The site includes:

- `index.html` — Main studio homepage and Between Checks showcase
- `apps.html` — Mobile app projects
- `games.html` — Independent game projects
- `app-ads.txt` — App advertising authorization file
- `Images/` — Website logos and project screenshots

## Status

The website is actively being updated as projects move through development and release.
